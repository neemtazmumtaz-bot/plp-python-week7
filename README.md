
# PLP Python Week 7 Assignment

## Assignment: File Handling and Report Builder

### Project Files

1. **my_notes.py** - Writes, appends, reads and counts notes in a text file.
2. **my_notes.txt** - Stores the four notes generated by my_notes.py.
3. **hubs.csv** - Contains learner names, hubs and scores.
4. **report_builder.py** - Reads CSV data, calculates results and generates a report.
5. **report.txt** - Contains the generated learner report.

### What happens if I change "a" to "w" in Question 1?

Changing append mode ("a") to write mode ("w") would erase the existing contents of the file before writing the new note. This means the first three notes would be lost and only the fourth note would remain.
